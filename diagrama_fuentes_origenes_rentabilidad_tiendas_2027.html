Fuentes detectadas

  • TIENDAS-current.xlsx: origen esperado para la hoja BASE_CONSOLIDADA; se transforma con scripts/refresh-base.mjs.
  • app/base-consolidada.ts: snapshot financiero embebido, generado el 2026-09-21T12:11:08.822Z.
  • public/data/market/national-source.csv: fuente local del Benchmark Nacional.
  • BIGQUERY_IMPORTS_TABLE: tabla de importaciones retail; default en forus-cl-planificacion.silver.ft_cl_planificacion_importaciones_industria.
  • BIGQUERY_TABLE: tabla de usuarios Talana; default en forus-cl-planificacion.Planificacion.ft_cl_planificacion_TB_STG_CL_TALANA_PERSONA.

Transformaciones clave

  • app/page.tsx agrega el snapshot por tienda, cadena, ano, mes y calcula ventas, margen, EBITDA, utilidad y Four Walls.
  • app/store-classification.ts clasifica tiendas en SSS y NS para 2026 y 2027 por mes.
  • docs/importaciones-industria-retail/REGLAS_NEGOCIO.json homologa marcas, importadores, segmentos, generos, tipos, clases y unidades.
  • app/api/importaciones-industria/route.ts detecta columnas reales en BigQuery y construye consultas agregadas para KPIs, tendencia, segmentos e importadores.

APIs internas

  • /api/auth/email valida correo corporativo activo contra BigQuery.
  • /api/auth/google valida token Google, dominio @forus.cl y usuario activo en BigQuery.
  • /api/auth/session y /api/auth/logout administran la sesion firmada.
  • /api/usuarios lista y actualiza rol/activo, restringido a administradores.
  • /api/config expone solo el client id publico o lo oculta si Google login esta deshabilitado.

Notas de revision

  • El flujo de B&L usa principalmente datos embebidos en frontend; refrescarlo requiere regenerar app/base-consolidada.ts.
  • Benchmark Nacional lee un CSV publico desde el navegador, sin pasar por API server.
  • Importaciones y Usuarios dependen de BigQuery y de las credenciales configuradas por ambiente.
  • Este archivo esta fuera del proyecto para revision externa y no modifica el repositorio.
